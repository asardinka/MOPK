# Оптимизация программы

## Ключевые изменения

### test1

Базовый вариант.

- Файлы читались построчно.
- Каждая строка разбиралась через `std::stringstream`.
- Парсинг, фильтрация, слияние и сортировка выполнялись отдельными этапами.

### test2

`std::stringstream` заменён на прямой поиск разделителей через `std::string::find()`.

Это убрало создание потокового объекта и работу через `streambuf` для каждой строки CSV.

### test3

Парсинг, фильтрация и слияние объединены в один проход.

Строки вне диапазона дат отбрасываются до создания `Row` и до преобразования `float64`. Исчезли промежуточные `rows` и `filteredRows`.

### test4

`std::stod(line.substr(...))` заменён на `std::from_chars()`.

Число преобразуется прямо из исходного буфера без создания временного `std::string`.

### test5

Для временной работы с именем и датой использован `std::string_view`.

Это уменьшило количество копирований строк в горячем цикле.

### test6

Проверен `std::map` вместо связки `unordered_map + vector + sort`.

Результат оказался медленнее из-за древовидной структуры, сравнений строк и разрозненного размещения узлов в памяти.

### test7

Проверена фиксированная таблица сумм.

Само накопление стало очень дешёвым, но выигрыш частично потерялся из-за двух `std::lower_bound()` для поиска `nameId` и `dateId`.

### test8

Поиск даты через `lower_bound` заменён прямым вычислением индекса дня.

Имя стало переводиться в `nameId` через `unordered_map<string_view, id>`.

### test9

`std::getline()` и `std::string::find()` заменены на чтение файла целиком в `std::vector<char>` и последовательный разбор CSV через `const char*`.

Это дало самый заметный прирост на позднем этапе оптимизации.

### test10

Финальный универсальный вариант.

Он сохраняет блочное чтение и разбор через указатели из `test9`, но больше не зависит от заранее известных имён и фиксированного диапазона дат.

- Имена обнаруживаются динамически.
- Дата преобразуется в число формата `YYYYMMDD`.
- Группа `name + date` кодируется компактным числовым ключом.
- Весь основной pipeline собран в функции `processFiles()`.

## Как работает итоговый вариант

Функция `processFiles()` принимает:

- список входных файлов;
- разделитель колонок CSV;
- разделитель даты;
- десятичный разделитель `float64`;
- начальную дату;
- конечную дату.

Для каждого файла выполняется следующий pipeline:

1. Файл читается целиком одним блоком в `std::vector<char>`.
2. CSV разбирается последовательным движением указателя по памяти.
3. Дата преобразуется в целое число `YYYYMMDD` и сразу фильтруется.
4. Имя представляется через `std::string_view` без копирования.
5. Каждому новому имени один раз назначается числовой `nameId`.
6. `float64` преобразуется непосредственно из диапазона `char`.
7. Пара `nameId + date` кодируется в один `uint64_t`, а сумма накапливается в `unordered_map`.
8. После обработки всех файлов создаётся итоговый `std::vector<Row>`.
9. Итоговый вектор сортируется по имени, затем по дате.

Формат даты предполагается `YYYY-MM-DD` или `YYYY.MM.DD` в зависимости от `dateSeparator`.
